# Modelo humano masculino

## Incluido en el proyecto

`human.obj` es el **Male Base Mesh CC0** (orange-juice-games / BoQsc), exportado con UV para rayar sobre la superficie.

Aspecto: cuerpo masculino base, liso y anatómico, ~1,82 m, fondo claro y sombreado suave en la app.

## Regenerar el modelo

```cmd
scripts\download-human-model.cmd
scripts\docker-init.cmd
scripts\run.cmd
```

## Respaldo procedural

Si borras `human.obj`, la app genera un maniquí procedural en pose A (`AnatomicalMaleMesh`).
